ข้อสอบ

1. การที่ธนาคารรับเงินฝากออมทรัพย์ซึ่งถอนได้ทุกเมื่อ แล้วนำไปปล่อยสินเชื่อบ้านอายุ 30 ปี เป็นหน้าที่ใดของตัวกลางทางการเงิน

  1. ก. การแปลงขนาด (Size Transformation)
  2. ข. การแปลงระยะเวลา (Maturity Transformation)
  3. ค. การแปลงความเสี่ยง (Risk Transformation)
  4. ง. ระบบการชำระเงิน (Payment System)

2. ถ้าอัตราเงินสำรองเท่ากับ 20% ตัวทวีเงินฝากอย่างง่ายเท่ากับเท่าใด

  1. ก. 5 เท่า
  2. ข. 20 เท่า
  3. ค. 0.2 เท่า
  4. ง. 80 เท่า

3. รายการใดเป็นรายได้ที่มิใช่ดอกเบี้ย (Non-interest Income) ของธนาคาร

  1. ก. ดอกเบี้ยรับจากสินเชื่อบ้าน
  2. ข. ค่าธรรมเนียมจากการขายประกันผ่านธนาคาร (Bancassurance)
  3. ค. ดอกเบี้ยรับจากพันธบัตรรัฐบาล
  4. ง. ดอกเบี้ยรับจากรายการระหว่างธนาคาร

4. รายการใดโดยทั่วไปเป็นสินทรัพย์ที่มีสัดส่วนสูงที่สุดในงบแสดงฐานะการเงินของธนาคารพาณิชย์

  1. ก. เงินรับฝาก
  2. ข. เงินให้สินเชื่อ
  3. ค. เงินสดและเงินฝากที่ ธปท.
  4. ง. ที่ดิน อาคาร และอุปกรณ์

5. ในงบกำไรขาดทุนของธนาคาร "กำไรก่อนสำรองและภาษี (PPOP)" คำนวณก่อนหักรายการใด

  1. ก. ดอกเบี้ยจ่าย
  2. ข. ค่าใช้จ่ายพนักงาน
  3. ค. รายได้ค่าธรรมเนียม
  4. ง. ผลขาดทุนด้านเครดิตที่คาดว่าจะเกิดขึ้น (Provision / ECL)

6. ลักษณะพิเศษของโครงสร้างเงินทุนธนาคารพาณิชย์เมื่อเทียบกับธุรกิจทั่วไปคือข้อใด

  1. ก. ใช้ส่วนของเจ้าของเป็นแหล่งเงินทุนหลัก
  2. ข. ไม่มีหนี้สินระยะสั้น
  3. ค. มีอัตราส่วนหนี้สินสูงมาก ส่วนของเจ้าของมักเป็นเพียงราว 10–15% ของสินทรัพย์
  4. ง. สินทรัพย์ส่วนใหญ่เป็นที่ดินและอาคาร

7. รายได้ดอกเบี้ยสุทธิ (Net Interest Income) คำนวณอย่างไร

  1. ก. ดอกเบี้ยรับ + รายได้ค่าธรรมเนียม
  2. ข. ดอกเบี้ยรับ − ค่าใช้จ่ายดำเนินงาน
  3. ค. ดอกเบี้ยรับ − ผลขาดทุนด้านเครดิต
  4. ง. ดอกเบี้ยรับ − ดอกเบี้ยจ่าย

8. อักษร L ใน CAMELS Rating หมายถึงด้านใด

  1. ก. Liquidity — สภาพคล่อง
  2. ข. Leverage — ระดับการก่อหนี้
  3. ค. Loan Quality — คุณภาพสินเชื่อ
  4. ง. Legal Compliance — การปฏิบัติตามกฎหมาย

9. อัตราส่วน Cost-to-Income ของธนาคารควรเป็นอย่างไรจึงถือว่ามีประสิทธิภาพดี

  1. ก. ยิ่งต่ำยิ่งดี
  2. ข. ยิ่งสูงยิ่งดี
  3. ค. ควรเท่ากับ 100% พอดี
  4. ง. ไม่เกี่ยวกับประสิทธิภาพ

10. อัตราส่วน NPL Ratio คำนวณจากข้อใด

  1. ก. สินเชื่อด้อยคุณภาพที่ค้างชำระเกิน 90 วัน หารด้วยสินเชื่อรวม
  2. ข. ค่าเผื่อผลขาดทุนหารด้วย NPL
  3. ค. สินเชื่อรวมหารด้วยเงินฝาก
  4. ง. กำไรสุทธิหารด้วยสินเชื่อรวม

11. อักษร C ใน CAMELS Rating หมายถึงด้านใด

  1. ก. Credit Risk — ความเสี่ยงด้านเครดิต
  2. ข. Cash Flow — กระแสเงินสด
  3. ค. Capital Adequacy — ความเพียงพอของเงินกองทุน
  4. ง. Customer — ฐานลูกค้า

12. อักษร S ใน CAMELS Rating หมายถึงด้านใด

  1. ก. Size — ขนาดของธนาคาร
  2. ข. Sensitivity to Market Risk — ความอ่อนไหวต่อความเสี่ยงด้านตลาด
  3. ค. Solvency — ความสามารถชำระหนี้ระยะยาว
  4. ง. Strategy — กลยุทธ์องค์กร

  4. ง. ROE ของ A มาจากการใช้หนี้มากกว่า จึงมีความเสี่ยงทางการเงินสูงกว่า B

  2. ข. แหล่งเงินทุนมั่นคงที่มีอยู่ เทียบกับที่ต้องมีในระยะ 1 ปี
  3. ค. เงินกองทุนเทียบกับสินทรัพย์เสี่ยง
  4. ง. สินเชื่อเทียบกับเงินฝาก
