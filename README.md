# Eash — ICT + Wyckoff Gold EA

EA สำหรับ XAUUSD ที่แปลงกฎจากเอกสาร "รวมความรู้ ICT และ Wyckoff สำหรับเทรดทองคำ" เป็นโค้ด พร้อม backtest ด้วยข้อมูล M1 จริง

> ไม่ใช่คำแนะนำการลงทุน ผล backtest ปัจจุบัน **ไม่พบความได้เปรียบ** (ดูหัวข้อผลทดสอบ) อย่าใช้กับเงินจริง

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `mql5/ICT_Wyckoff_Gold_EA.mq5` | EA สำหรับ MetaTrader 5 |
| `backtest/engine.py` | ตัวจำลองที่ใช้ตรรกะเดียวกับ EA (สัญญาณตอนแท่งปิด, จำลองการ fill ด้วยแท่ง M1) |
| `backtest/download_data.py` | โหลดแท่ง M1 ของ XAUUSD จาก HistData.com |
| `backtest/run_backtest.py` | รันชุดทดสอบแล้วเขียน `results/REPORT.md` |
| `results/` | รายงาน, รายการไม้ (`trades_M*.csv`), equity รายวัน, ตาราง grid |

## กฎที่ EA ใช้ (อ้างอิงหัวข้อในเอกสาร)

1. **วันเทรด** เริ่ม 17:00 นิวยอร์ก งดศุกร์แรกของเดือน (NFP) และวันที่ระบุใน `InpNoTradeDates` (ข้อ 7)
2. **Bias รายวัน** (ตารางข้อ 7): แท่งเมื่อวานปิดทะลุจุดสูง/ต่ำของวันก่อน = ไปต่อ, ไส้ทะลุแล้วปิดกลับ = กลับตัว, inside day = ไม่เทรดฝั่ง ICT
3. **Kill Zone** (ข้อ 6): London 02:00–05:00 และ New York AM 07:00–10:00 เวลานิวยอร์ก งด 08:15–08:45 (ข่าว 08:30)
4. **สภาพคล่องที่รอให้ถูกกวาด** (ข้อ 3): จุดสูง/ต่ำช่วงเอเชีย, Previous Day High/Low, จุดสูง/ต่ำช่วงลอนดอน (สำหรับรอบนิวยอร์ก), จุดสูง/ต่ำเก่าบน H1 เฉพาะจุดที่ยังไม่ถูกกวาดก่อนเข้า Kill Zone
5. **Wyckoff** (ข้อ 12–15): หากรอบไซด์เวย์จาก 72 แท่ง H1 (แตะขอบบนและล่างอย่างน้อยฝั่งละ 2 ครั้ง ราคาไม่ไหลทางเดียว) การกวาดขอบล่าง = Spring (Buy), กวาดขอบบน = UTAD (Sell) เป้า TP1 กลางกรอบ, TP2 ขอบฝั่งตรงข้าม
6. **2022 Mentorship Model** (ข้อ 8): หลังกวาด ต้องมีแท่งปิดทะลุ swing ย่อยล่าสุด (MSS) ภายใน 120 นาที โดยขานั้นมีแท่ง Displacement (ตัวแท่ง ≥ 1.5 เท่าของค่าเฉลี่ย 20 แท่ง) และทิ้ง FVG ที่ยังไม่ถูกเติมเกินครึ่ง
7. **จุดเข้า**: Limit ที่ขอบ FVG (เลือก CE 50% หรือบังคับโซน Discount/Premium ได้)
8. **Stop Loss**: เลยจุดที่กวาด เผื่อ 0.5 × A (A = ค่าเฉลี่ย high-low 20 แท่ง ใช้แทนค่า "1–2 ดอลลาร์" ในเอกสาร เพื่อให้ปรับตามระดับราคาและความผันผวน)
9. **Take Profit**: TP2 = สภาพคล่องฝั่งตรงข้ามที่ใกล้ที่สุดที่ให้ Risk:Reward ≥ 1:2 ถ้าไม่มีเป้า = ไม่เข้า, TP1 = จุดสูงย่อยฝั่งตรงข้ามตัวแรก (อย่างน้อย 1R)
10. **จัดการไม้** (ข้อ 8): ถึง TP1 ปิด 50% แล้วเลื่อน SL เท่าทุน, แท่งปิดสวนทะลุ FVG ที่ใช้เข้า = ปิดเอง, ราคาถึง TP1 ก่อนย่อมาเข้า = ยกเลิกออเดอร์, ปิดทุกไม้ 16:00 นิวยอร์ก
11. **ความเสี่ยง** (ข้อ 9): 1% ต่อไม้, lot = เงินที่ยอมเสีย ÷ ระยะ SL ปัดลง, สูงสุด 2 ไม้ต่อวัน, แพ้ครบ 2 ไม้หยุดวันนั้น

สิ่งที่เอกสารพูดถึงแต่ **ยังไม่ได้ทำ**: Smart Money Technique (SMT) Divergence, การอ่าน Volume (ข้อมูลทองสปอตไม่มี volume จริง), Silver Bullet, Unicorn, Turtle Soup, Weekly Profile, ปฏิทินข่าวอัตโนมัติ, เพดานขาดทุนรายสัปดาห์/รวมบัญชี

## ผลทดสอบ

รายละเอียดเต็มอยู่ที่ [`results/REPORT.md`](results/REPORT.md)

- ข้อมูล XAUUSD M1 ตั้งแต่ 2 ม.ค. 2024 ถึง 6 พ.ย. 2026 (737 วันเทรด) ทุน 6,000 ดอลลาร์ spread 0.30 ดอลลาร์ คอมมิชชัน 7 ดอลลาร์ต่อ lot
- ค่าเริ่มต้นของ EA ขาดทุนทุก timeframe: M5 14 ไม้ −1.3%, M3 20 ไม้ −3.3%, M1 77 ไม้ −10.6%
- ทดสอบ 96 ชุดค่า: ชุดที่มีไม้ช่วง in-sample ตั้งแต่ 30 ไม้ขึ้นไปมี 24 ชุด ไม่มีชุดใดได้กำไรทั้ง in-sample และ out-of-sample
- กฎเข้มตามเอกสารบน M5 ให้สัญญาณน้อยมาก (ราว 5 ไม้ต่อปี) จำนวนไม้ไม่พอสรุปทางสถิติ
- ไม้ส่วนใหญ่ออกด้วยกฎ "แท่งปิดทะลุ FVG" ก่อนถึงเป้า และเป้าสภาพคล่อง TP2 ถูกแตะน้อยครั้ง

## วิธีใช้

### Backtest ด้วย Python

```bash
pip install pandas numpy requests
python3 backtest/download_data.py 2023 2026   # โหลดข้อมูลลง data/
cd backtest && python3 run_backtest.py --grid # เขียน results/REPORT.md
```

ปรับค่าได้ที่ `Params` ใน `backtest/engine.py` ชื่อและค่าเริ่มต้นตรงกับ input ของ EA

### ใช้ใน MetaTrader 5

1. คัดลอก `mql5/ICT_Wyckoff_Gold_EA.mq5` ไปที่ `MQL5/Experts/` แล้ว compile ใน MetaEditor
2. แปะบนกราฟ XAUUSD timeframe M5 (หรือ M1/M3)
3. ตั้ง `InpServerMinusNY` = เวลาเซิร์ฟเวอร์โบรกเกอร์ลบเวลานิวยอร์ก (โบรกเกอร์ GMT+2/+3 ส่วนใหญ่ = 7)
4. ทดสอบใน Strategy Tester โหมด "Every tick based on real ticks" และบัญชี demo ก่อนเสมอ

ไฟล์ `.mq5` ยังไม่ได้ compile หรือรันใน MetaTrader 5 (สภาพแวดล้อมที่ใช้พัฒนาไม่มี MetaEditor) ผลทดสอบทั้งหมดมาจากตัวจำลอง Python

## ข้อจำกัดของ backtest

- ข้อมูลเป็นราคา BID ใช้ spread คงที่ ไม่จำลอง spread ถ่างช่วงข่าวหรือ slippage
- ถ้า SL และ TP อยู่ในแท่ง M1 เดียวกัน ถือว่าโดน SL ก่อน
- ข้อมูล HistData ช่วง ก.พ.–ก.ค. 2023 มีช่องโหว่รายชั่วโมง จึงเริ่มทดสอบจากปี 2024
- ราคาและเวลาของโบรกเกอร์จริงต่างจากข้อมูลนี้ได้ ผลใน Strategy Tester อาจไม่ตรงกัน
